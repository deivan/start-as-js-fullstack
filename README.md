# Базовий курс для фулл стек веб розрбника (2025)
Обов'язкова вимога для студента - мати базові впевнені знання у HTML, CSS, Javascript, ще бажано Git.
Послідовно, крок за кроком ми будемо занурюватись у веб розробку як на стороні бекенду, так і на стороні фронтенду. Наша мета - це створити повноцінну веб аплікацію з сервером, авторизацією, сайтом, адмінкою, нардами та гуріями.

## План занятть (адженда) на 24 пари:

### 01. Введення у веб розробку. Клієнт-серверна архітектура (1 пара). Засоби розробки.
Що таке протоколи HTTP/HTTPS. Що відбувається, коли я набрав адресу сайту у браузері та натиснув кнопку Ентер. З чого почати шлях розробника - яку потрібно мати зброю. Що таке Git та GitHub (GitLab, Bitbucket, etc.).
Перше знайомство, переваги Node.js над конкурентами. Інсталяція на локальний комп'ютер. Поєднання з засобом розробки VS Code. Запуск скриптів у консолі. Вбудовані модулі та їх підключення.

### 02. Серверна середа виконання скриптів на мові Javascript - Node.js (1 пара)
Відмінності виконання скриптів у Node.js та у браузері. Створення найпростішого серверу. Вивчення об'єктів Request та Response. Можливі типи даних у відповіді, що повертає веб-сервер.

### 03. Встановлення фреймворку Nest.JS та базові налаштування для роботи (1 пара)
Встановлення головного модулю Nest CLI та використання його з командною строкою для створення аплікації. Структура проекту та взаємодія між файлами. Архітектура Модуль - Контроллер - Провайдер. Запуск проекту, вбудовані засоби відладки.

### 04. Основи мови TypeScript (1 пара)
Сумісність з Javascript, середа виконання. Сувора типизація, інтерфейси. Композитні типи даних. Дженеріки та їх зв'язок з інтерфейсами. Обробка помилок на етапі компіляції коду TypeScript. Робота з функціями, об'єктами та класами. Розширення та успадкування. Generic Object Types.
