# Початковий курс для фулл стек розрбника на Javascript
Послідовно, крок за кроком ми будемо занурюватись у веб розробку як на стороні бекенду, так і на стороні фронтенду. Наша мета - це створити повноцінну онлайн гру з сервером, авторизацією, сайтом, адмінкою, нардами та гуріями.

## План занятть (адженда):

### 1. Введення у веб розробку. Клієнт-серверна архітектура (1 пара)
Що таке протоколи HTTP/HTTPS. Що відбувається, коли я набрав адресу сайту у браузері та натиснув кнопку Ентер. З чого почати шлях розробника - яку потрібно мати зброю. Що таке Git та GitHub (GitLab, Bitbucket, etc.).

### 2. Серверна середа виконання скриптів на мові Javascript - Node.js (2 пари)
Перше знайомство, переваги Node.js над конкурентами. Інсталяція на локальний комп'ютер. Поєднання з засобом розробки VS Code. Запуск скриптів у консолі. Вбудовані модулі та їх підключення. Відмінності виконання скриптів у Node.js та у браузері. Створення найпростішого серверу. Об'єкти Request та Response.
