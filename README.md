# Створення статичного фронтенду

План проведення заняття:

## 01. Підготовчі процедури

Витягуємо цей лессон з репозиторію локально на свій комп'ютер. У студента вже має бути встанолений глобально пакет фреймворку `Nest.js`

Виконуємо команду `npm i`

## 02. Запускаємо веб аплікацію

Виконуємо команду `npm run start:dev` для перевірки що все працює локально у браузері на адресі `localhost:3000`

Для подальшого ознайомлення з концепцією `Model-Vie-Controller` у фреймворку `Nest.js` читаємо цю статтю: https://docs.nestjs.com/techniques/mvc#template-rendering

## 03. Вивчаємо роботу шаблонізаторів на прикладі Pug

Ознайомлюємось з матеріалом:  https://pugjs.org/api/getting-started.html
    
На базі цього матеріалу починаємо створювати свій шаблон домашньої сторінки для майбутнього сайта нашої веб аплікації.

## 04. Будуємо статичний сайт нашого проєкту з декількома сторінками

Ціль заняття - створити статичний сайт на декілька сторінок, які будуть добре індексуватися системами пошуку. Зараз ми працюємо у концепції SSR, тобто статичного рендерінгу на боці серверу. Для красивого розмалювання наших статичних сторінок ми будемо використовувати стильові фреймворки Bootstrap чи Tailwind.

### 04.1. Спочатку розмалюємо всі частини лейауту сайту

На цьому етапі ми маємо закласти бачення, як буде виглядати сайт взагалі - його кольорова схема, інфографіка, постфйні елементи структури, такі як хідер та футер. За бажанням можна додати механізм кольорових тем.

### 04.2. Тепер додамо сторінки на базі створеного лейауту

А тепер ми створимо всі необхідні початкові статичні сторінкі та додамо туди базовий контент. Окремо - додамо дані з серверного боку, ці дані в майбутньому будуть динамічно змінюватись відповідно ситуації. Наприклад, ми можемо створити якийсь рекламний блок, контент якого буде братися на сервері.
