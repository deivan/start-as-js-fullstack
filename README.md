## 01. Введення у веб розробку. Клієнт-серверна архітектура. Засоби розробки 

Уявіть собі, що ви хочете прочитати цікаву книжку. Текстовий файл - це як звичайна книга, де кожен символ відповідає літері. Щоб її прочитати, вам потрібен "читач" - текстовий редактор, наприклад, Блокнот. Але якщо книга написана іншою мовою або має складнішу структуру, наприклад, PDF-файл, вам знадобиться спеціальний "перекладач" - програма, яка розуміє цей формат.

Так само є і в мережі Інтернет. Веб-сторінки - це як складні книги, що містять текст, зображення та інші дані. Щоб їх побачити, нам потрібен "перекладач" - веб-браузер _ _(Chrome, Safari, Firefox, Edge, Opera, ...)_ _, який вміє "розмовляти" з веб-серверами та відображати отриману інформацію у зрозумілому для нас вигляді.

Набір правил, що дозволяють комп'ютерам обмінюватися даними, називається протоколом передачі даних. У веб-розробці найпоширенішими протоколами є HTTP та HTTPS. HTTP - це протокол передачі гіпертексту, який використовується для отримання веб-сторінок. HTTPS - це той самий HTTP, але з доданим шифруванням для безпечної передачі даних.

Апаратно-програмний комплекс, що надає веб-сторінки та інші дані для браузерів, називається веб-сервером. Програмне забезпечення, що працює на веб-сервері та відповідає за обробку запитів від клієнтів, називається веб-аплікацією. Браузер на комп'ютері користувача називається веб-клієнтом.

Для спрощення, далі ми будемо використовувати терміни "сервер", "клієнт" та "аплікація", маючи на увазі саме веб-сервер, веб-клієнт та веб-аплікацію відповідно.

### Як працює запит до веб-сервера

Введення адреси: Користувач вводить адресу веб-ресурсу (URL) у адресний рядок браузера та натискає Enter. Наприклад, https://www.example.com.

DNS-запит: Браузер звертається до DNS-сервера, щоб отримати IP-адресу, що відповідає доменному імені www.example.com. DNS-сервер - це як адресна книга інтернету, що допомагає знаходити потрібні сервери за їх іменами.

Встановлення з'єднання: Браузер встановлює TCP-з'єднання з веб-сервером за отриманою IP-адресою. TCP - це протокол, що забезпечує надійну доставку даних між комп'ютерами.

HTTP-запит: Браузер надсилає HTTP-запит на сервер. Цей запит містить інформацію про те, який ресурс потрібен (наприклад, головна сторінка сайту). HTTP - це протокол, за яким браузери та сервери обмінюються даними.

Обробка запиту сервером: Веб-сервер отримує запит та обробляє його. Сервер може виконувати різні дії, залежно від запиту:

- Зчитування файлів з диска (для статичних сторінок).
- Виконання програмного коду (для динамічних сторінок).
- Звернення до бази даних для отримання інформації.
- Формування відповіді: Сервер формує HTTP-відповідь, яка містить запитувані дані (HTML-код сторінки, зображення, тощо) та іншу службову інформацію.

Відправлення відповіді: Сервер надсилає HTTP-відповідь браузеру.

Відображення сторінки: Браузер отримує відповідь та обробляє її. Браузер "розбирає" HTML-код та відображає сторінку на екрані користувача.

### Що відбувається на стороні веб-сервера

__Отримання запиту__: Сервер постійно "слухає" певний порт (зазвичай 80 для HTTP та 443 для HTTPS) на предмет нових запитів від клієнтів (браузерів).

__Розбір запиту__: Сервер аналізує отриманий HTTP-запит, щоб зрозуміти, який ресурс потрібен клієнту та які параметри запиту.

__Пошук ресурсу__: Сервер шукає відповідний ресурс на своєму диску або в базі даних.
Обробка запиту: Якщо ресурс потребує обробки (наприклад, виконання скрипту), сервер виконує необхідні дії.

__Формування відповіді__: Сервер створює HTTP-відповідь, яка містить запитуваний ресурс та іншу службову інформацію.

__Відправлення відповіді__: Сервер надсилає сформовану відповідь клієнту.

### Важливість використання Git для розробки

Git - це не просто інструмент для збереження коду, це потужна система контролю версій, яка є критично важливою для сучасної розробки програмного забезпечення. Використання Git надає розробникам безліч переваг, які значно підвищують ефективність, якість та безпеку їхньої роботи.

__Контроль версій та історія змін__: Git дозволяє зберігати історію всіх змін, що відбувалися з кодом протягом розробки. Ви завжди можете повернутися до будь-якої попередньої версії, щоб виправити помилку, відновити втрачений код або порівняти зміни між різними версіями. Це особливо важливо при роботі над складними проектами, де легко заплутатися у змінах.

__Спільна робота та командна розробка__: Git значно спрощує спільну роботу над проектом. Кілька розробників можуть працювати над різними частинами коду одночасно, а потім легко об'єднати свої зміни в одну. Git також надає інструменти для вирішення конфліктів, які можуть виникнути при злитті змін.

__Безпека та резервне копіювання__: Git забезпечує безпечне зберігання коду та його резервне копіювання. Навіть якщо ваш комп'ютер вийде з ладу, ви завжди зможете відновити свій проект з репозиторію Git.

__Гілкування та експерименти__: Git дозволяє створювати гілки - окремі лінії розробки, де ви можете експериментувати з новими функціями або виправленнями помилок, не впливаючи на основну гілку проекту. Після успішного тестування зміни з гілки можна легко об'єднати з основною гілкою.

__Відстеження помилок та співпраця з іншими розробниками__: Git інтегрується з багатьма інструментами для відстеження помилок та управління проектами, що полегшує співпрацю з іншими розробниками та тестувальниками.

__Освіта та розвиток__: Git є стандартом в індустрії розробки програмного забезпечення. Знання Git є обов'язковим для кожного сучасного розробника. Вивчення Git відкриває доступ до безлічі ресурсів, спільнот та можливостей для професійного розвитку.

Використання Git є невід'ємною частиною сучасного процесу розробки. Git допомагає зробити розробку більш ефективною, безпечною та зручною, а також сприяє кращій співпраці між розробниками.

### Переваги використання VS Code для веб-розробки

Visual Studio Code (VS Code) - це потужний та безкоштовний редактор коду, розроблений Microsoft, який швидко завоював популярність серед веб-розробників завдяки своїй універсальності, продуктивності та широким можливостям налаштування.

__Швидкість та легкість__: VS Code відомий своєю швидкістю та легкістю. Він швидко запускається та працює навіть з великими проектами, не споживаючи багато ресурсів комп'ютера. Це дозволяє розробникам зосередитися на коді, а не на очікуванні завантаження редактора.

__Підтримка сучасних веб-технологій__: VS Code має вбудовану підтримку HTML, CSS, JavaScript та інших сучасних веб-технологій. Він надає підсвічування синтаксису, автозаповнення коду, інструменти для відлагодження та багато інших функцій, які полегшують розробку веб-сайтів та додатків.

__Велика екосистема розширень__: VS Code має величезну екосистему розширень, які дозволяють розширити функціональність редактора та налаштувати його під свої потреби. Ви можете знайти розширення для підтримки різних мов програмування, фреймворків, інструментів для роботи з базами даних, систем контролю версій та багато іншого.

__Інтеграція з Git__: VS Code має вбудовану інтеграцію з Git, що дозволяє розробникам працювати з репозиторіями безпосередньо з редактора. Ви можете створювати коміти, переглядати історію змін, зливати гілки та виконувати інші операції Git, не виходячи з VS Code.

__Кросплатформність__: VS Code працює на Windows, macOS та Linux, що робить його ідеальним вибором для розробників, які працюють на різних операційних системах.

__Активна спільнота та підтримка__: VS Code має активну спільноту розробників, які постійно працюють над покращенням редактора та створенням нових розширень.

Завдяки своїм перевагам, VS Code є одним з найкращих редакторів коду для веб-розробки. Він поєднує в собі швидкість, функціональність та можливість налаштування, що робить його ідеальним інструментом для створення сучасних веб-сайтів та додатків.

### Користь використання Git Bash на Windows

Для розробників, які працюють на операційній системі Windows, Git Bash є незамінним інструментом, що надає доступ до багатьох корисних функцій та можливостей. Ось деякі з них:

__Звичне середовище Linux__: Git Bash надає користувачам Windows звичне командне середовище, схоже на Linux. Це особливо корисно для розробників, які мають досвід роботи з Linux або macOS, оскільки більшість команд та інструментів командного рядка є однаковими.

__Доступ до Unix-подібних інструментів__: Git Bash включає в себе багато Unix-подібних інструментів, таких як ls, cd, grep, sed, awk та інші. Ці інструменти є дуже потужними та корисними для автоматизації завдань, обробки тексту та виконання інших операцій з файлами та каталогами.

__Зручна робота з Git__: Git Bash забезпечує зручний та ефективний спосіб роботи з системою контролю версій Git. Ви можете виконувати всі необхідні операції Git, такі як клонування репозиторіїв, створення комітів, злиття гілок та інші, безпосередньо з командного рядка.

__Інтеграція з іншими інструментами розробки__: Git Bash може бути легко інтегрований з іншими інструментами розробки, такими як текстові редактори, IDE та інші. Це дозволяє розробникам використовувати Git Bash для виконання команд та операцій, не виходячи зі свого звичного робочого середовища.

__Покращена продуктивність__: Використання Git Bash може значно підвищити продуктивність розробників, особливо при виконанні завдань, які потребують використання командного рядка. Завдяки звичному середовищу та доступу до Unix-подібних інструментів, розробники можуть швидше та ефективніше виконувати свою роботу.

Git Bash є потужним та корисним інструментом для веб-розробників, які працюють на Windows. Він надає доступ до багатьох функцій та можливостей, які спрощують та покращують процес розробки.
