# Створення статичного фронтенду

План проведення заняття:

## 01. Підготовчі процедури

Витягуємо цей лессон з репозиторію локально на свій комп'ютер. У студента вже має бути встанолений глобально пакет `Nest.js`

Виконуємо команду `npm i`

## 02. Запускаємо веб аплікацію

Виконуємо команду `npm run start:dev`
