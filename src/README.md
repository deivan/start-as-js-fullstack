### Як перевірити працездатність зв'язки REST + WS

1. Запустіть екземпляр Redis (docker run -p 6379:6379 -d redis).

2. Запустіть Nest.js застосунок за допомогою npm run start:dev.

3. Виконайте HTTP GET запит на адресу http://localhost:3500/api/chat-system/status. Ви отримаєте JSON-відповідь про поточний стан інфраструктури з activeConnections: 0.

4. Підключіться будь-яким WebSocket-клієнтом (наприклад, Postman) за адресою ws://localhost:3500/chat.

5. Повторіть HTTP запит — лічильник activeConnections динамічно зміниться на 1. Це підтверджує коректну роботу DI та взаємодію всіх створених шарів архітектури.
